# Isomorphic Strings (C++)

## 📌 Problem Statement

Given two strings `s1` and `s2`, determine whether they are isomorphic.

Two strings are isomorphic if the characters in `s1` can be replaced to get `s2`, while preserving the order of characters.

Each character must map to exactly one character, and no two different characters can map to the same character.
